# CPS 3498 Lab 1 — Identity & Security Website

Static website prepared for GitHub Pages. Upload `index.html`, `style.css`, and this README into a new GitHub repository.


## Publish with GitHub Pages
1. Create a new public GitHub repository (e.g. `CPS3498-Lab1-Identity-Security`).
2. Upload the files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish; your live link will appear in the Pages settings.
